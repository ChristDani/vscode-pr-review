# vscode-pr-review

Adds convenient buttons to Visual Studio Code for reviewing and managing Git branches directly from the Source Control view.

## Features

- Branch review actions available from the Source Control interface.
- Faster access to common branch-related operations.
- Actions integrated into the standard VS Code workflow.

## Requirements

Visual Studio Code 1.85.0 or later and a Git repository.

## Extension Settings

This extension does not currently contribute any configurable settings.
